# GlowMark 1.1.0 (Fabric, Minecraft 26.3, только клиент)

## Что умеет
- Клавиша Y: экран со списком игроков сервера. Галочка рядом с ником = игрок отмечен.
- Отмеченные всегда подсвечены (как после спектральной стрелы). Клавиша H включает/выключает подсветку.
- Поиск по нику, пинг рядом с ником.
- Оповещения в чат + звук: отмеченный зашёл на сервер / вышел / появился рядом (радиус настраивается).
- Радар в action bar: три ближайших отмеченных игрока и дистанция до них.
- Список и настройки сохраняются в config/glowmark.json.

## Зависимости
Для игры (в папку mods):
- Minecraft Java Edition 26.3
- Fabric Loader 0.19.5 или новее
- Fabric API 0.161.0+26.3 или новее
- Java 25 (идёт вместе с лаунчером Minecraft 26.x)

Для сборки:
- JDK 25
- Gradle 9.6.0
- Fabric Loom 1.17 (подтягивается сам из build.gradle)

## Сборка
1. `gradle build`
2. Готовый мод: build/libs/glowmark-1.1.0.jar (не *-sources.jar)

Без установки JDK/Gradle: залей папку в новый репозиторий на GitHub,
вкладка Actions -> build -> Artifacts -> glowmark-jar.
